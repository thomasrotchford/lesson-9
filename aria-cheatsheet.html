ARIA and Accessibility

ARIA adds information that helps screen readers understand webpages. It makes websites more accesible for people with disabilities.

ARIA Roles

Roles tell screen readers what an element does. There are six catagories.

  • Abstract Roles: Define basic role types. Examples: command, widget.
  • Widget Roles: Identify interactive controls. Examples: button, checkbox.
  • Document Structure Roles: Organize page content. Examples: article, heading.
  • Landmark Roles: Identify important page areas. Examples: main, navigation.
  • Live Region Roles: Announce changes. Examples: alert, status.
  • Window Roles: Identify popup windows. Examples: dialog, alertdialog.

Note: ARIA standards say authors MUST NOT use abstract roles in webpage content.

ARIA Properties

Properties give screen readers extra informtion about elements.

  • Widget Attributes: Describe controls.
    • aria-autocomplete - Text suggestions.
    • aria-placeholder - Input hint.
    • aria-valuemin - Minimum value.
  • Live Region Attributes: Describe content updates.
    • aria-live - Announcement timing.
    • aria-atomic - Amount announced.
    • aria-relevant - Changes announced.
  • Drag-and-Drop Attributes: Describe dragging actions.
    • aria-dropeffect="copy" - Copies.
    • aria-dropeffect="move" - Moves.
    • aria-dropeffect="link" - Creates links.
    • Relationship Attributes: Connect seperate elements.
      • aria-controls - Controlled element.
      • aria-describedby - Description.
      • aria-labelledby - Label.

ARIA States

States show an element's current condition, which can change during use.

  • Widget Attributes: Show control conditions.
    • aria-checked="true" - Checked.
    • aria-expanded="false" - Closed.
    • aria-selected="true" - Selected.
  • Live Region Attributes: Show update progress.
    • aria-busy="true" - Updating.
  • Drag-and-Drop Attributes: Show dragging status.
    • aria-grabbed="true" - Grabbed. Now deprecated.
  • Relationship Attributes: Describe connections, not states.
    • No state attributes in this category.
